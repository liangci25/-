## 四、手工验收步骤（给使用者）

1. 双击 `index.html`，等开场动画结束，见三个图标。
2. 进「忆梦」→ 新建会话 → 进聊天 → 点右上「⋯」→「让对方说话」，观察 1~3 条回复先后出现；点左下「＋」升起功能面板。
3. 在聊天页长按一条消息 → 弹出「引用 / 收藏 / 删除」菜单：点引用后输入框上方出现引用条，发出去气泡里带引用块；点收藏提示「已收藏」；点删除需再确认一次。
4. 进「字卡库」→ 右上菜单 → 批量添加，粘贴：
   ```
   【问候】
   在的。
   刚忙完。
   ```
   确认预览统计与分组创建。
5. 进「设置」→ 导出全部数据 → 再导入，确认会话与字卡复原。
