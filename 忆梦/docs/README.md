# 忆梦 · 交付说明（v1.0）

纯静态、单人使用、移动端优先的角色对话模拟器。**双击 `index.html` 就能用**，不需要装任何东西、不需要联网。

---

## 一、怎么打开

1. 打开文件夹 `Desktop\忆梦`。
2. 双击 `index.html`。
3. 浏览器地址栏会是 `file:///.../index.html`，属于正常现象。

手机上看：把整个「忆梦」文件夹拷到手机，用支持本地文件的浏览器打开 `index.html`；或者起一个局域网服务后在手机里访问。**页面按 375px 设计**，桌面浏览器里会居中成一条 430px 的手机屏。

---

## 二、能做什么（本期 P0 全量）

### 1. 桌面与外观
- 三个 APP 图标：**忆梦**（聊天）/ **字卡库** / **设置**，符合「功能打包成图标」的要求。
- 开场动画：逐字展开 + 下划线生长 + 光晕，可点击跳过，可在设置里关掉；**整个浏览器会话只播一次**，从任何子页返回桌面直接进主界面。
- 日夜切换三态（日间 / 夜间 / 跟随系统），全站黑白灰，单一强调色。
- 宋体字族为默认，可改字号（12~22）、字体族、字体文件地址。
- 名称、头像、时间戳、已读标记各有独立开关；时间戳默认隐藏，**点消息才出现**；已读样式可切「文字 / 双勾 / 圆点」。
- 气泡四套模板 + 自定义 CSS（自己 / 对方分开），自定义内容走白名单过滤。
- 聊天背景：无 / 纯色 / 图片，带遮罩浓度调节。

### 2. 聊天
- 多会话：会话列表 → 聊天，每会话独立角色名、头像、参数、背景、字卡来源。
- 列表右上「＋」点开一枚贴着按钮的小弹窗，上下两条：**加好友**（压在主界面之上的一层半透明玻璃卡片，宽度 = 主界面宽 − 32、水平居中，背后的列表照旧看得见：每一位都是一组「头像 / 名称 / 头像直链」——点头像上传本地图，名字填在右边，直链在它下面那一行粘贴后实时解析并报尺寸；点「＋ 再添加一位」可以一次填好几位、一起建，每行右侧「×」去掉多余的那位；只建一位时直接进聊天，多位则留在列表并提示建了几个）、**创建群聊**（与加好友同一套卡片：左头像、右群名，下面一行群头像直链，再下面是「群成员（至少两个）」的多选胶囊；候选成员与会话列表同步，会话里删掉的角色不会再出现），点空白处收起。角色不足两个时，群聊会提示并直接转到「加好友」。
- 角色绑定：会话名就是角色名，建会话时自动生成/复用同名角色并绑定；该角色的专属字卡会参与这个会话的回复抽取（单聊同样生效）。
- 底部是「＋ / 输入框 / 纸飞机」三件套：点「＋」升起功能面板（每页 6 项、3 列 2 行，超过 6 项自动分页并可横向滑动，带页点指示），**相册**可多选图片 / 视频发进聊天（图片会自动缩到最长边 1080、压成 JPEG，视频限 2MB），**拍照**直接调系统相机拍完就发，图片点一下能全屏看大图（再点一下收起），视频用原生播放控件；分享 尚未接入；**视频通话**是模拟的：点开就是全屏通话画面（头像居中、底部静音 / 挂断两枚按钮），先「正在呼叫…」约 2.4 秒，七成会被接起来开始计时，没接上就落一条「视频通话 · 无人接听」，中途点「取消」落「视频通话 · 已取消」；**角色也会主动打来**——判定按时段走——每个小时进到这个小时时摇一次 5%~8% 的概率，中了就在这一小时里随机挑一分钟响，一天可以来几通、不设上限；不管当时停在哪个页面：在聊天页会弹整屏来电（「邀请你视频通话」，头像轻轻呼吸，底部左边绿色「接听」、右边红色「拒绝」），在别的页面则在顶部浮一条小横幅（头像 + 名字 + 拒绝 / 接听），点接听会跳回该会话的聊天页直接接通；接听转成通话计时，拒绝落「视频通话 · 已拒绝」，一直不理 22 秒算无人接听；我拨出去时按 65:15:20 出结局：六成半接听、一成半「对方已拒绝」、两成「无人接听」，中途点「取消」落「已取消」；对方没接上的话，过二三十秒会主动回拨过来，来电层照常可以接听 / 拒绝 / 不理；左上角圆形返回键和底部挂断都能回聊天——返回键是**最小化**：通话不断、计时照走，聊天页右下会留一个带着头像和通话时长的悬浮按钮，点它就回到通话页；挂断会落一条「视频通话 · 00:12」，全程不调用摄像头。**红包**已可用：弹层里二选一「红包 / 转账」，填金额（≤99999）和备注（≤20 字，留空用默认话术），发出去在聊天里成为一张卡片（红包暖红底白字、转账常规底），点卡片即标成已领取 / 已收款并整卡降透明度。**问卷**也已接入：弹层铺满屏幕（吸顶「问卷 + 关闭」、中间滚动、取消 / 发送贴底），分「发出 / 收到」两段——「发出」里自己出题（题目 ≤5、每题选项 2~4，可增删），发出去后聊天里是一张问卷卡片，先「待填写」，4~12 秒后角色逐题选一个答案点亮成「已填写」，点卡片可弹出整份问卷看全部题目与答案；「收到」列出本会话所有问卷与对方的答案，已填的卡片底部还有一行「填写于 …」——一个月内说相对说法（「刚刚 / 5分钟前 / 3小时前 / 一天前 / 3天前 / 一个星期前 / 两个星期前 / 三个星期前」），满一个月起落到绝对时间（如「26年11月8日20时44分」），未填的卡片没有这行，点一条就在同一个全屏界面里打开这份问卷的完整题目与答案，不用回聊天找那条消息。**群聊**里面板第六项换成「投票」：底部弹出的小面板写一句题干（≤20 字）+ 2~4 个选项（每个 ≤12 字，可增可删），发出去是一张投票卡（题干、选项逐行、右侧票数、底部一条比例细线），点某一项就是自己那一票（可改投），群里其余成员几秒后陆续补上票，卡片右上角显示「已投 / 总人数」。「让对方说话」在右上 ⋯ 菜单里，触发后从字卡池随机抽 **1~3 条**，**每条独立延迟**（默认 3~10 秒，可在参数里改 1~120 秒）。
- 已读不回：每次让对方说话掷一次点，命中则整组不回，但仍然标「已读」。
- 主动发消息：分钟级随机（默认 30~90 分），循环触发、可关；与「让对方说话」两套计时器互不打断。
- 引用回复：从近十条里挑一条挂在回复组第一条上。
- 连句：一组回复合并成一条，用随机符号分隔（符号可增删）。
- 群聊：每条回复随机成员，**一组回复绑定同一成员**；成员在设置里维护，头像名称独立。
- 正在输入指示器，文案可全局改、也可按会话覆盖。
- 长按消息，气泡正下方贴出一条横排工具条：引用（回到输入框并挂上引用条，发出后气泡里带引用块）、收藏（存在消息的 `favorited` 上，可再点一次取消）、删除（二次确认）；点一下只做选中高亮。清空记录在个人资料页。
- 消息音效：内置 3 条，可上传自定义音效、可关、对方侧可随机播放列表、会话级三态继承。
- 通知降级：页内顶部提示条 + 标题前缀（`file://` 下系统通知不可用，这是浏览器限制）。

### 3. 字卡库
- 两个根：**通用**（全会话共用）与**专属**（按角色独占），**分组在各自根内部独立**。
- 专属根顶部是**角色下拉**：会话里建过的角色全在列，选中谁就管理谁的字卡（添加上传、编辑、导出、分组、屏蔽、删除都作用在当前角色）；下拉与「搜索字卡」并排一行，通用根时搜索框铺满。
- 分组：新建、重命名、上移下移、屏蔽、删除（连带字卡）。
- 内容分三类，搜索框上方一排二级 tab 可切换：**字卡 / 表情包 / emoji**，每个 tab 带本类条数。分类按内容自动判定——图片直链进「表情包」、纯表情进「emoji」、其余进「字卡」；切换时搜索框提示语和空态文案跟着变，互不串。
- 搜索行最左侧是四个裸图标：**导入 / 导出 / 分组 / 管理**（2×2 排开、不套底板，与搜索胶囊之间留 8px 空档），搜索框占这一行剩下宽度。「⋯」只保留排序方式与全库去重。
- 字卡：单条添加、批量添加（`【分组名】` 起组，每行一条）、编辑、移动分组、屏蔽、删除（5 秒撤销）。表情包用图片直链添加（列表显示缩略图），emoji 直接输入表情。
- 表情包不参与自动回复（图片不能当文字发出去），emoji 与字卡照常进回复池。
- 分类 / 排序（手动、最近添加、文本长度、字母）/ 搜索（200ms 防抖）/ 全库去重。
- 批量模式：勾选、批量移动、批量删除。
- JSON 导入（结构校验 + 预览 + 统计）与 JSON 导出（导出当前根，专属根导出当前角色，文件名如 `忆梦字卡_专属_阿凛_2026-11-08.json`）。JSON 里保留分组名、分组屏蔽态与字卡屏蔽态；导入兼容纯数组 / `{groups:[…]}` 两种写法，按当前根合并去重。

### 4. 个人资料
- 聊天页顶部只有返回、会话名和一个「⋯」：点 ⋯ 进**个人资料页**（当前会话的角色）。上方是角色头像（点了可换）与居中的名字，下面是一列标签页式的行：**聊天设置 / 置顶聊天 / 聊天背景 / 查找聊天记录 / 清空聊天记录**（不做「一起听」）。
- **聊天设置**是弹层：顶部两个按钮「让对方说话」「去字卡库」，往下是回复节奏、主动消息、对话形式（引用 / 连句 / 群聊 + 成员）、正在输入、消息音效三态，改完即时生效并存进该会话。
- **置顶聊天**行尾是绿胶囊「已置顶」／灰胶囊「未置顶」，点一下切换；置顶的会话排到会话列表最上面。
- **聊天背景**单独一个弹层（跟随全局 / 无 / 纯色 / 图片 + 遮罩，可上传也可贴直链），行尾显示当前状态「已设置 / 跟随全局 / 无」。
- **查找聊天记录**只搜这个会话，命中词高亮，点结果跳回聊天页并滚到那条消息。
- 换头像会同步回会话与角色，字卡库下拉、设置里的角色名跟着变（改名入口已按用户要求去掉）。
\n- 聊天里点**我自己的头像**进「我的资料」：上方是我的头像（点了可换）与名字，下面是**头像 / 昵称 / 签名**三行；改完回到会话，我的消息上的头像与名字一并跟着变。\n
### 5. 信笺
- 桌面第四个图标，进去是**信袋**，上面分「收到 / 发出」两段：收到的来信、自己寄出的信各看各的。
- 一列信的卡片，按时间倒序，信封式的纸色卡片显示标题、时间、正文前两行和「写给 X / X 寄来」，没收过的信右下有个小红点。
- 长按一封（或用读信页右上角的「删除」）能把这封信删掉，删前会再问一次。
- 点一封打开**信纸**：米白纸面、内嵌细线框，纸底一朵栀子线描；标题居中，正文宋体大字、首行缩进，末尾一条叶绿细线下面右对齐落款；打开即标为已读。写信也是同一张信纸。
- 右上笔形按钮**写一封**：填标题（可不填）和正文，点「封好寄出」。信发出去几秒后，对方会回一封——回信会自己出现在列表里并标未读。
- 写给谁：写信页吸顶栏的「写给 ◯◯」是个下拉，点开列出**会话列表里的角色**（最近说过话的排前面，**群聊不算**），挑一个就写给他；还没建会话时只有「远方的人」。

### 6. 潮汐
- 一页内置月历（周一起头、六行 42 格），上方三段「日程 / 经期 / 睡眠」——**三个分段共用同一份日历**，切换不收起日历，只换标记口径。
- 右上角那枚按钮**随分段换功能**：日程下是「回到今天」，经期下点开「经期设置」（周期长度、经期长度），睡眠下点开「睡眠设置」（目标时长）。
- **日程**：点某天就选中那天，日历下方列出这天的计划，可以一条条加、一条条删；有计划的日子在数字下面点一个小点。
- **经期**：在日历上点两下圈出一段（第一下起日、第二下讫日，点已记的日子整段取消），一段里每天铺浅底、两端更深；日历下方按时间倒序列出「往期经期」，点一条跳回那个月。经期印记只在经期分段出现，日程 / 睡眠看到的是干净日历。
- **睡眠**：目前只有目标时长与一行状态，还没有记录功能。

### 7. 设置与数据
- 外观、聊天体验、通知、数据、关于五个分区（角色管理那一块已整块移除）。
- 全量导出 / 导入（导入前显示会话数、消息数、字卡数并确认；自动留备份）。
- 恢复自动备份、重置全部数据（须手输「重置」二次确认）。

## 三、文件结构

```
忆梦/
├─ index.html                 桌面 + 开场动画（唯一放根目录的页面，双击它）
├─ pages/
│  ├─ sessions.html           会话列表（底部「会话 / 朋友圈」双 tab）
│  ├─ moments.html            朋友圈（发文字 / 照片 / 地点 / @ / 可见范围）
│  ├─ chat.html               聊天（回复引擎接线）
│  ├─ cards.html              字卡库
│  ├─ profile.html            个人资料（当前会话角色）
│  ├─ me.html                 我的资料（点头像进这一页）
│  ├─ letters.html            信笺（写信 / 读信）
│  ├─ tide.html               潮汐（内置日历）
│  ├─ mirror.html             共鉴（空态占位）
│  ├─ sync.html               共时（空态占位）
│  ├─ resonance.html          共振（空态占位）

├─ css/
│  ├─ common.css              设计令牌与公共组件
│  ├─ index.css / sessions.css / moments.css / chat.css / cards.css / profile.css / letters.css / settings.css / tide.css / mirror.css / sync.css / resonance.css
├─ js/
│  ├─ common.js               内核（存储/事件/UI/主题/音效/回复/任务/通知）
│  └─ index.js / sessions.js / moments.js / chat.js / cards.js / profile.js / letters.js / settings.js / tide.js / mirror.js / sync.js / resonance.js
├─ docs/
│  ├─ README.md               本文件
│  ├─ NAMING.md               命名唯一权威（四级编号）
│  ├─ TESTING.md              测试记录
│  └─ 忆梦-PRD-v1.0.md         需求文档
└─ tools/*.py                 自检与浏览器探针脚本
```

约定：`pages/*.html` 引用 `../css/*.css` 与 `../js/*.js`；页间互跳同级相对；回桌面用 `../index.html`。一页一套 html/js/css；跨页共享的东西只放 `js/common.js` 与 `css/common.css`；数据全在 `localStorage`。

## 五、实际验证结果

- 自动检查：`python tools/selfcheck.py` — JS 语法、HTML 标签配对、id 引用、文件引用、命名清单对照，**全部通过**。
- 真实浏览器（无头 Chrome，`file://`）：五页全部加载无报错（已按新目录 `pages/` 路径重跑），种子数据正确渲染。
- 核心闭环：「⋯」→「让对方说话」→ 3 条回复按延迟落库、引用块出现、已读标记出现；发送消息成功。
- 按钮抽查：字卡单条添加（3→4 行）、切专属根（角色下拉出现）、设置开关持久化、字号即时生效、新建会话并跳转。
- 本轮三条修改专项：开场动画第二次进入不重播；单聊会话能取到绑定角色的专属字卡；专属根下拉列出全部会话角色且切换即切内容；新建会话只填名字，自动生成同名角色并写入 `memberId`。
- 明细见 `docs/TESTING.md`（§2.4 为本轮专项，另含「已验证 10 条 / 未验证清单」）。

## 六、未验证项（如实说明）

以下功能代码已写完，但**没有实测证据**：已读不回的掷点表现、主动消息计时、群聊成员分配、连句符号、正在输入、音效上传与随机、通知条、删除/清空、加入字卡库弹窗、会话重命名/换头像/复制/删除、分组全套操作、批量语法解析、JSON 字卡导入导出、全量导入导出与重置、日夜切换细节、气泡白名单拦截、字体文件加载、容量警告与损坏恢复、移动端真机。

原因：无头浏览器用虚拟时间，只能验证「按计划投递」，无法覆盖真实体感与文件选择框（上传头像/音效/图片需要在有界面的浏览器里手动点）。这些需要在真实浏览器里过一遍，`TESTING.md` 第四节给了手工验收步骤。

---

## 七、已知限制

1. `file://` 下系统通知弹不出来 → 已降级为页内提示条 + 标题变化。
2. 浏览器完全关闭后计时器停止；重开时由 `ym_runtime_v1` 接管过期任务（补投最多 3 条）。
3. 体积上限：头像 300KB、背景 500KB、单条音效 200KB（最多 10 条）、单次导入 3000 条字卡。
4. 用户消息 ≤500 字、字卡 ≤200 字、分组名 ≤12 字、会话名 ≤20 字。

## 八、后续新增功能怎么做

1. 先在 `NAMING.md` 找到归属模块，分配下一个编号并登记；改完在 §10 变更记录加一行。
2. 新页面 = 新的 `x.html/x.css/x.js` 三件套；新入口加到桌面图标网格。
3. 涉及数据的，同步考虑是否要并入全量导出导入（当前导出是整份 `ym_data_v1`，新增字段会自动带上，只要在 `defaultData` 里给默认值）。
4. 改完跑 `python tools/selfcheck.py`，再按 `TESTING.md` 补一条用例。
